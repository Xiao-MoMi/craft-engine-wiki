# 📜 Denizen

:::tip
If you encounter problems when using the Denizen features provided by CraftEngine, please [give us feedback](https://github.com/Xiao-MoMi/craft-engine/issues/new) in time. If you'd like to request a new Denizen feature and you know Java, consider contributing your code via a pull request!
:::

:::warning
You need to install [Denizen](https://ci.citizensnpcs.co/job/Denizen/).
:::

In all event lines, the word `ce` can also be written as `craftengine`, e.g. `on player breaks craftengine block block:` works the same as `on player breaks ce block block:`.

CraftEngine ids (like `default:wooden_chair`) can be used directly in event lines and command arguments — the plugin registers all loaded namespaces with Denizen automatically, no extra escaping needed.

## Commands

<SkriptCard
  title="PlaceCEBlock"
  type="Command"
  description="Places CraftEngine custom blocks in the world. Blocks are specified as CraftEngine block ids, optionally with block state properties. ~waitable"
  syntax={[
    'placeceblock [<location>|.../<ellipsoid>/<cuboid>] [<craftengine_block>|...] (no_physics) (<percent chance>|...) (silent)'
  ]}
  values={[
    'no_physics - place without physics taking over the modified blocks',
    'silent - skip placement sounds; sounds play by default. Can be combined with no_physics and percentage chances',
    '(<percent chance>|...) - chances are rolled in order per location until one succeeds; if no roll succeeds, the location is left unchanged. "50|50" means 50% the first block, 25% the second, 25% unchanged'
  ]}
  examples={[
    `- placeceblock <player.cursor_on> default:sugar_block`,
    `- placeceblock <player.cursor_on> default:sugar_block silent`,
    `- ~placeceblock <player.cursor_on> default:togglable_light_block[light=15] no_physics`,
    `- placeceblock <player.location.to_cuboid[<player.cursor_on>]> default:sugar_block|default:cloud_block 50|50`
  ]}
  defaultOpen={false}
/>

<SkriptCard
  title="SpawnCEFurniture"
  type="Command"
  description="Spawns CraftEngine furniture in the world. ~waitable"
  syntax={[
    'spawncefurniture [<location>|.../<ellipsoid>/<cuboid>] [<craftengine_furniture>|...] (direction:north/east/south/west) (<percent chance>|...)'
  ]}
  values={[
    'direction: - controls the direction the furniture faces',
    '(<percent chance>|...) - chances are rolled in order per location until one succeeds; if no roll succeeds, nothing is spawned at that location'
  ]}
  examples={[
    `- spawncefurniture <player.cursor_on> default:wooden_chair`,
    `- ~spawncefurniture <player.cursor_on> default:oak_lamp direction:west`
  ]}
  defaultOpen={false}
/>
