# ⌨️ Skript

:::tip
For advanced skript users, please use reflection to achieve more advanced functions. If you encounter problems when using the Skript features provided by CraftEngine, please [give us feedback](https://github.com/Xiao-MoMi/craft-engine/issues/new) in time. If you'd like to request a new Skript feature and you know Java, consider contributing your code via a pull request!
:::

:::warning
You need to install [Skript](https://modrinth.com/plugin/skript) 2.15.0+.
:::


## Types

CraftEngine registers two extra types that can be stored in variables. Parse them from strings with `parsed as`:

```applescript
# A full immutable block state (id + properties)
set {_state} to "default:table_lamp[lit=true,facing=east]" parsed as custom block state

# A block state matcher, mostly used in event filters
set {_matcher} to "default:table_lamp[lit=true]" parsed as unsafe block state matcher
```

Unquoted literals also work in effects and event filters, e.g. `place custom block default:table_lamp[lit=true] at player`.

## Expressions

<SkriptCard
  title="CraftEngine Item"
  type="Expression"
  description="Get custom item from namespace id"
  syntax={[
    '[(the|a)] (custom|ce|craft-engine) item [with [namespace] id] %strings%',
  ]}
  examples={[
    `set {_item} to custom item with namespace id "default:topaz"`
  ]}
  defaultOpen={false}
/>

<SkriptCard
  title="CraftEngine Item Id"
  type="Expression"
  description="Get a namespace id of custom item"
  syntax={[
    '(custom|ce|craft-engine) item [namespace] id of %itemstack/itemtype/slot%',
    '%itemstack/itemtype/slot%\'[s] (custom|ce|craft-engine) item [namespace] id'
  ]}
  examples={[
    `set {_itemId} to craft-engine item id of player's tool`
  ]}
  defaultOpen={false}
/>

<SkriptCard

<SkriptCard
  title="CraftEngine Block State Property"

## Effects

<SkriptCard
  title="Place CraftEngine Block"
  type="Effect"
  description="Place a custom block"
  syntax={[
    'place (custom|ce|craft-engine) block %customblockstates% [at] [%directions% %locations%]',
  ]}
  examples={[
    `place custom block default:palm_log[axis=x] at location of the player`
  ]}
  defaultOpen={false}
/>

<SkriptCard
  title="Place CraftEngine Furniture"
  type="Effect"
  description="Place a furniture, optionally with a specific variant"
  syntax={[
    'place [(custom|ce|craft-engine)] furniture[s] %strings% [with variant %-strings%] [at] [%directions% %locations%]',
  ]}
  examples={[
    `place furniture "default:bench" at location of player`,
    `place furniture "default:flower_basket" with variant "wall" at location of player`
  ]}
  defaultOpen={false}
/>

<SkriptCard
  title="Remove CraftEngine Block"
  type="Effect"

  syntax={[
    '(remove|break) (custom|ce|craft-engine) block[s] [at] [%directions% %locations%]',
  ]}
  examples={[
    `remove custom block at target block`
  ]}
  defaultOpen={false}
/>

<SkriptCard
  title="Remove CraftEngine Furniture"

  ]}
  examples={[
    `remove craft-engine furniture target entity`
  ]}
  defaultOpen={false}
/>

<SkriptCard
  title="Force Set CraftEngine Furniture Variant"
