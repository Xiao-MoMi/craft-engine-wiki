本章将完成插件安装，并配置资源包分发。

## 要求

CraftEngine 支持以下 Paper 系服务端：

**Paper 及其下游**：Paper、Purpur、Pufferfish、Leaf、Leaves、UniverseSpigot

**Folia 及其下游**：Folia、Canvas、Luminol

:::info
- **Java：** JDK 21 或更高
- **Minecraft：** 1.20 或更高
:::

## 资源包托管

CraftEngine 会将你的内容生成资源包，供玩家下载。默认配置使用插件内置 HTTP 服务，即 `self` 自托管。

**先测试默认配置**：进入游戏并执行 `/ce reload all`。如果资源包能够正常下载，且没有出现紫黑贴图，就说明托管已经生效。默认配置使用 `self` 模式，由服务器直接通过 HTTP 分发资源包，无需额外设置。

配置方式见[资源包托管](set_up_host)，生成和上传步骤见[工作流](workflows)。

修改 `resource-pack.packs` 或 `resource-pack.self-host` 后，运行 `/ce reload host` 即可更新托管设置。还需要重新构建资源包时，使用默认工作流的服务器可执行 `/ce reload all`，也可以通过 `/ce workflow [名称]` 执行自己的构建工作流。

> ⚠️ 对于需要 API 密钥的托管方式（如 S3），请通过**环境变量**提供密钥，不要将密钥直接写入 `config.yml`，也不要把含有密钥的配置文件发给不信任的人。
