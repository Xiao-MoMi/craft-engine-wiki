---
title: 外部托管
id: external
---

```yaml
resource-pack:
  packs:
    development:
      type: external
      default: true
      url: "https://packs.example.com/development.zip"
      # 可选：此 URL 对应 ZIP 文件的 SHA-1。
      # sha1: "0123456789abcdef0123456789abcdef01234567"
      # 可选：省略时根据 URL 生成 UUID。
      # uuid: "123e4567-e89b-12d3-a456-426614174000"
```

:::info

将资源包托管在外部服务器上。  
这可以避免资源包占用你自己服务器的带宽。

通常，在你将资源包上传到托管平台后，它会提供给你以下信息：

- URL（资源包下载链接）
- UUID（可选）
- SHA1（可选）

将这三个选项填入配置即可。

:::

:::caution

为确保玩家始终收到最新版本，需要手动定期更新外部托管的资源包。

:::
