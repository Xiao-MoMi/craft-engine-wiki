:::tip
如果在使用 CraftEngine 提供的 Denizen 功能时遇到问题，请[提交反馈](https://github.com/Xiao-MoMi/craft-engine/issues/new)。如果希望添加新的 Denizen 功能并熟悉 Java，也欢迎通过拉取请求贡献代码。
:::

:::warning
你需要安装 [Denizen](https://ci.citizensnpcs.co/job/Denizen/)。
:::

在所有事件行中，`ce` 也可以写成 `craftengine`，例如 `on player breaks craftengine block block:` 与 `on player breaks ce block block:` 效果相同。

CraftEngine 的 ID（如 `default:wooden_chair`）可以直接写入事件行和命令参数。插件会自动向 Denizen 注册所有已加载的命名空间，无需额外转义。

  syntax={[

    'no_physics - 放置时不让物理更新影响被修改的方块',

  ]}
  examples={[
    `- placeceblock <player.cursor_on> default:sugar_block`,
