本教程将带你从零开始，使用 CraftEngine 为 Minecraft 服务器添加自定义物品、方块、家具和图片。每学完一章，你都能在游戏中看到自己的成果。

## 准备

开始前，请准备好：

- 一个运行 Minecraft 1.20+ 的 Paper 系服务端，并已安装 CraftEngine
- 一款支持 YAML 的文本编辑器
- （可选）用于制作模型的 [Blockbench](https://www.blockbench.net/)

如果尚未安装插件，请先阅读[安装与托管](./getting_start/installation)。

## 关键命令

教程中会反复用到以下命令：

| 情况 | 命令 |
|:---|:---|
| 修改 `.yml` 配置（物品、方块等） | `/ce reload config` |
| 修改合成配方 | `/ce reload recipe` |
| 修改工作流定义、触发条件或步骤 | `/ce reload config` |
| 修改包 ID 或托管设置 | `/ce reload host` |
| 修改模型或贴图文件 | `/ce reload all` |
| 执行指定资源包工作流 | `/ce workflow [名称]` |

`config` 只更新工作流定义，不执行工作流。`all` 还会执行由 `reload_pack` 触发的工作流，默认的 `development` 工作流会构建并发送资源包。如果使用其他工作流，请通过 `/ce workflow [名称]` 显式执行。各重载模式的区别见[命令参考](./reference/commands#reload)。

遇到问题时，请先检查控制台；CraftEngine 会在那里输出大多数错误信息。

准备好后，从[安装与托管](./getting_start/installation)开始。
