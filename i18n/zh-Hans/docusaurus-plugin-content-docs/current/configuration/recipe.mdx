## 准备工作

配置新配方前，建议先了解标签、物品来源和配方解锁等基础概念。

### 标签

CraftEngine 支持原版标签和自定义标签。引用标签时使用 `#namespace:tag` 格式。

:::tip

部分合成插件无法为物品分配标签，也不能在配方中引用标签。例如，新建的木板类型可能无法与原版木板共同参与配方。CraftEngine 的标签支持可以解决这类兼容问题。

:::

以下示例为 `palm_planks` 添加两个原版标签，使其能够参与数据包中引用这些标签的配方。

```yaml
items:
  default:palm_planks:
    material: paper
    settings:
      fuel_time: 300
      tags:
        - "minecraft:planks"
        - "minecraft:wooden_tool_materials"
    data:
      item_name: "<!i>棕榈木板"
```

### 数据组件谓词

谓词允许你为配方原料设置除物品 ID 或标签之外的额外条件，例如特定魔咒或数据组件。

```yaml
recipes:
  default:sharpness_upgrade:
    type: shapeless_transform
    ingredients:
      - items: minecraft:diamond_sword
        source: true
      - items: minecraft:paper
        predicate:
          - type: enchantment
            enchantments:
              minecraft:sharpness: 5
    result:
      id: default:topaz_sword
      count: 1
```

<MinecraftRecipe
  pattern={['SP ', '   ', '   ']}
  ingredients={{
    S: items.diamondSword,
    P: {...items.paper, enchanted: true, lore: [{text: '条件：锋利 V', color: '#ffaa00'}]},
  }}
  result={items.topazSword}
/>

可用谓词类型：

```yaml
# 检查魔咒
- type: enchantment
  enchantments:
    minecraft:sharpness: 5

# 精确数据组件匹配（高级）
- type: exact
  component: minecraft:custom_name
  value: ... # NBT 标签值
```

:::tip[获取准确的组件值]

手持源物品并运行 [`/ce debug item-component [组件] [json/snbt]`](../reference/commands.mdx#debug-item-component)。点击结果将其复制，然后把完整的 `(json) ...` 或 `(snbt) ...` 字符串粘贴到 `value` 中。请保留格式前缀。

:::

### 分组 / 标签栏

```yaml
recipes:
  default:palm_planks:
    type: shapeless
    category: building
    group: planks
    ingredients:
      A: "#default:palm_logs"
    result:
      id: default:palm_planks
      count: 4
```

`group` 指定配方在客户端解锁后所属的分组。分组名可以自定义，但不能包含中文等非法字符。

同一标签栏中，使用相同 `group` 的配方会合并为一个配方格，并轮换显示组内的物品。下面的棕榈木板和橡木木板都属于 `planks`：左键选择当前配方，右键展开组内的原料布局，再点击具体配方查看合成预览。触屏可点按展开；键盘聚焦配方格后按 ↓ 展开，Esc 关闭。

<MinecraftRecipeBook recipes={recipeBookRecipes} initialCategory="building" label="配方分组示例" />

`category` 决定该配方在配方书中所属的标签栏，可选类型有限。

点击配方书左侧的标签，查看建筑、装备、杂项和红石配方。选中配方后，下方会显示它的 `category` 和 `group`。

<MinecraftRecipeBook recipes={recipeBookRecipes} label="配方标签栏示例" />

* 烧炼配方可选：`food`（食物）、`blocks`（方块）、`misc`（杂项）。
* 合成配方可选：`building`（建筑）、`redstone`（红石）、`equipment`（装备）、`misc`（杂项）。

### 与其他插件的兼容性

首先，将支持的插件添加到 `config.yml` 中的此列表：

```yaml
recipe:
  ingredient-sources:
    - MythicMobs
```

:::info
支持的物品来源请参阅[📦️ 外部物品来源](../compatibility/external_item_sources.mdx)。你也可以通过 API 注册自定义物品来源。
:::

接下来需要将每个外部物品源映射到对应的 CraftEngine 等效物，请参考以下配置示例：

```yaml
items: 
  mythicmobs:kingscrown:
    material: golden_helmet
    data:
      external:
        plugin: MythicMobs
        id: KingsCrown
    settings:
      tags:
        - add_tag:if_you_want # 可选：添加标签
```

之后，只需像创建其他普通物品一样为该物品创建配方即可。

```yaml
recipes:
  default:bench:
    type: shaped
    pattern:
      - A A
      - A A
    ingredients:
      A: mythicmobs:kingscrown
    result:
      id: default:bench
      count: 1
```

:::caution

对于用作原料的任何物品，你必须确保它们在 CraftEngine 中的命名空间是**小写**的插件名称，并且路径也应该是**小写**的。以下是一些示例，以便你了解其工作原理：

* MythicMobs 中名为 `MySword` 的物品 → `mythicmobs:mysword`
* CustomFishing 中名为 `star_fish` 的物品 → `customfishing:star_fish`
* MMOItems 中名为 `MAGIC_GEM` 且类型为 `MATERIAL` 的物品 → `mmoitems:material_magic_gem`
* 某个**其他插件**中具有命名空间 ID 的物品 → `random_plugin:namespace_id`

:::

### 结果后处理器

**结果后处理器**是为解决配方多样化需求引入的概念。例如，如果你想制作一把镐子，但希望输出的镐带有魔咒，那么为每个已附魔的物品都创建一个单独的配方是不切实际的。

```yaml
result:
  id: default:topaz_pickaxe
  count: 1
  post_processors:
    - type: apply_data
      data:
        enchantment:
          minecraft:efficiency: 5
```

:::info
目前为止，只有 apply_data 类型的后处理器。你可以使用 API 注册新的后处理器。
:::

### 转化处理器

转化处理器用于转换配方（`smithing_transform`、`shaped_transform` 和 `shapeless_transform`），控制源物品的数据如何合并到结果中。

```yaml
transform_processors:
  # 将物品数据应用于合并的物品上
  - type: apply_data
    data: 
      item_name: "新名称"

  # 合并结果和原料的魔咒信息，而不是保留其中之一
  - type: merge_enchantments

  # 保留 custom_data 组件的特定数据（1.20.5+）
  - type: keep_custom_data
    paths:
      - weapon
      - energy.fly

  # 保留指定组件（1.20.5+）
  - type: keep_components
    components:
      - minecraft:enchantments

  # 保留指定 NBT 标签（1.20–1.20.4）
  - type: keep_tags
    tags:
      - display.Name
      - CustomModelData
```

### 视觉结果

<Highlight color="#f2184eff">**付费版专属**</Highlight>

视觉结果功能能够防止玩家提前预知合成/锻造配方的结果。这对于包含随机化物品的配方特别有用。

```yaml
result:
  id: default:topaz_sword
  count: 1
visual_result:
  id: default:topaz_sword
  count: 1
  post_processors:
    - type: apply_data
      data:
        remove_components:
          - attribute_modifiers
        lore:
          - "<gray>攻击伤害 1~3"
          - "<gray>攻击速度 1~2"
```

### 函数

<Highlight color="#f2184eff">**付费版专属**</Highlight>

当物品成功合成/锻造时，可利用函数执行特定操作。

```yaml
recipes:
  default:bench:
    functions:
      - type: command
        command: say 1
```

### 条件

<Highlight color="#f2184eff">**付费版专属**</Highlight>

条件允许为该配方设定要求，从而阻止不符合这些条件的玩家使用。

```yaml
recipes:
  default:bench:
    conditions:
      - type: permission
        permission: recipe.unlock.bench
```

### 配方解锁

#### 自动解锁

如果玩家拥有了该配方的所有原料且满足此配方的条件，则自动为玩家解锁该配方。该选项默认值可在 `config.yml` 里设置。

```yaml
recipes:
  default:amethyst_torch:
    unlock_on_ingredient_obtained: true
```

#### 进服解锁

设为 `true` 时，玩家进服后会自动解锁该配方，无需先获取原料。

```yaml
recipes:
  default:amethyst_torch:
    unlock_on_join: true
```

也可以在 `config.yml` 中全局控制此行为：

```yaml
recipe:
  unlock-on-join:
    all: false   # 是否在进服时解锁全部配方
    list:        # 额外在进服时解锁的配方 id
      - default:amethyst_torch
```

### 无序合成转化配方

无序合成转化配方与无序合成配方类似，但必须将一个原料标记为 `source: true`。源物品的数据会被合并到最终结果中，适合用于升级已有物品。

```yaml
recipes:
  default:topaz_sword_transform:
    type: shapeless_transform
    ingredients:
      - items: minecraft:diamond_sword
        source: true  # 设置为源物品
      - default:topaz
    # 是否将源物品的组件合并到结果中
    merge_components: true # 默认值：true
    result:
      id: default:topaz_sword
      count: 1
    transform_processors:
      - type: keep_components
        components:
          - enchantments
```
