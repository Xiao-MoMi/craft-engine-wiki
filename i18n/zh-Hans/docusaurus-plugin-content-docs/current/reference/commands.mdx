CraftEngine 的大部分命令以 `/craftengine`（缩写 `/ce`）开头，少数为独立的玩家命令（如 `/search-recipe`、`/search-usage`）。每条命令的启用状态、权限节点与命令路径都记录在 `plugins/CraftEngine/commands.yml` 中，可在其中自由修改（修改后需重启生效）。多数命令支持 `--silent`（简写 `-s`）标志以静默执行、不回显消息。

下文中 `[ ]` 表示必填参数，`( )` 表示可选参数。

## 基础命令

### reload

`/ce reload (config/recipe/host/pack/all)`

不带参数时默认为 `config`。默认权限：`ce.command.admin.reload`。

| 参数 | 行为 |
|:---|:---|
| `config` | 重载配置，包括工作流定义、触发条件和步骤。 |
| `recipe` | 重载配置与配方，同时更新工作流定义。 |
| `host` | 重载配置及资源包托管设置，包括 `resource-pack.packs` 和 `resource-pack.self-host`。 |
| `pack` | 执行当前已加载、`trigger` 包含 `reload_pack` 的工作流。 |
| `all` | 重载配置、配方、托管设置和工作流定义，然后执行 `reload_pack` 工作流。 |

修改 `resource-pack.workflows` 后，执行 `/ce reload` 或 `/ce reload config` 即可更新。`/ce reload pack` 使用已加载的工作流，不会重新读取配置。是否生成、上传或发送资源包，取决于被触发工作流中的步骤。

### workflow

`/ce workflow [名称]`

执行 `resource-pack.workflows` 中指定的工作流，例如 `/ce workflow production`。Tab 补全列出已加载的工作流。默认权限：`ce.command.admin.pack_workflow`。

按顺序执行工作流中配置的步骤，即使没有设置 `trigger` 也能手动执行。`trigger` 支持字符串或列表，例如 `trigger: reload_pack` 或 `trigger: [reload_pack]`。

原 `/ce upload` 命令已由工作流的 `upload` 步骤替代。仅上传不会自动重发；需要向当前使用指定包的在线玩家发送更新时，应添加 `send_pack` 步骤。步骤中的 `pack` 必须对应 `resource-pack.packs` 中的包 ID。

### pack

`/ce pack [enable/disable/reset] [包ID] (玩家)`

保存玩家的资源包偏好。包 ID 对应 `resource-pack.packs` 中的条目。

- `enable`：显式启用该包。
- `disable`：显式禁用该包。
- `reset`：删除偏好覆盖，恢复使用该包配置中的 `default` 值。

省略玩家时修改自己的偏好。指定目标时，填写准确的在线玩家名或 UUID；离线玩家须使用 UUID。控制台必须指定目标。玩家执行者需要 `ce.resourcepack.<包ID>` 权限；此命令在 `commands.yml` 中的默认权限节点为空。

修改在线玩家对本服已配置包的偏好后，会重新发送该玩家选中的资源包。本服未配置的包 ID 也可以保存偏好并更新缓存，但不会触发重发。离线玩家的数据会在下次选择资源包时使用。

```text
/ce pack enable production
/ce pack disable development
/ce pack reset production Steve
```

### clean-cache

`/ce clean-cache [类型]`

清理自动分配的缓存数据。可用类型：`custom_model_data`、`custom_block_states`、`visual_block_states`、`font`、`all`（默认）。插件重载时不可执行。

## 物品命令

### item browser

`/ce item browser [玩家]`

为指定玩家打开物品浏览器（管理端）。

`/ce`

玩家可直接输入 `/ce` 为自己打开物品浏览器（快捷方式）。

![](/img/commands_15.png)

### item get

`/ce item get [物品标识符] (数量)`

获取指定数量的物品（1–9999，默认 1）。

### item give

`/ce item give [玩家] [物品标识符] (数量)`

给予玩家指定数量的物品。

### item clear

`/ce item clear [玩家] [物品标识符] (最大数量)`

移除玩家物品栏中匹配的 CraftEngine 物品。`最大数量` 为 `0` 时仅统计不删除。可用 `--match-tag` 标志按物品标签匹配。

### item search-recipe / search-usage

`/ce item search-recipe [玩家] [物品标识符]`

`/ce item search-usage [玩家] [物品标识符]`

为指定玩家打开物品的配方/用途查询界面。

`/search-recipe [物品标识符]`

`/search-usage [物品标识符]`

玩家查询自身物品的配方/用途。

![](/img/commands_16.png)

### item custom-model-data

`/ce item custom-model-data [值]`

设置主手物品的自定义模型数据值（仅玩家）。

### item item-model

`/ce item item-model [值]`

设置主手物品的物品模型（命名空间 ID，仅玩家，1.21.2+）。

### item remove-component

`/ce item remove-component [组件]`

移除主手物品上指定的数据组件（仅玩家，1.20.5+ 组件版本）。

## 功能命令

### feature send-pack

`/ce feature send-pack [玩家]`

根据指定玩家的已保存偏好及各包的 `default` 设置，重新发送其选中的资源包。资源包按配置顺序发送，尚不可用的包无法发送。此命令不负责生成或上传资源包。

### feature totem-animation

`/ce feature totem-animation [玩家] [物品标识符] (音效) (音量) (音高) (最小音量) (最小音高)`

为玩家播放不死图腾动画。可用 `--no-sound` 标志静音。

![](/img/commands_14.png)

### feature toast

`/ce feature toast [类型] [物品] [消息]`

给自己发送一个弹窗（成就提示，仅玩家）。`类型` 为弹窗框样式：`task`、`challenge` 或 `goal`；`物品` 为图标（命名空间物品标识符）；`消息` 为显示文本，支持 MiniMessage。可用 `--silent`（`-s`）标志静默执行。

### feature locale

`/ce feature locale set [玩家] [区域设置]`

设置玩家的语言区域。

`/ce feature locale unset [玩家]`

取消玩家的语言区域设置。

### feature toggle-entity-culling

`/ce feature toggle-entity-culling [玩家] (状态)`

开启/关闭玩家的实体剔除。`状态` 为 `true`/`false`，省略则切换。

### feature entity-culling-distance-scale

`/ce feature entity-culling-distance-scale set [玩家] [缩放比率]`

设置玩家的实体剔除距离缩放比率（0.125–8）。

### feature display-entity-view-distance-scale

`/ce feature display-entity-view-distance-scale set [玩家] [缩放比率]`

设置玩家的展示实体可视距离缩放比率（0.125–8）。

### feature place-feature

`/ce feature place-feature [特性标识符] (位置)`

在指定位置放置原版已配置特性（configured feature，仅玩家）。省略位置时使用玩家当前坐标。

### feature migrate-world-storage

`/ce feature migrate-world-storage [世界] [方向] [类型]`

迁移世界区块存储格式。`类型` 为 `mca`、`pdc` 或 `linear`，且不能是配置文件中当前启用的存储类型。`方向` 为 `from` 或 `to`：

- `from`：从指定类型迁移**到**当前启用的存储类型——请先在配置中切换目标存储类型，再从旧类型迁移。
- `to`：从当前启用的类型迁移**到**指定类型，完成后会提示你在配置中更新存储类型并重启服务器。

仅支持 Paper，同一时间只能运行一个迁移任务。

### feature clear-world-storage

`/ce feature clear-world-storage [世界] [类型]`

删除指定世界中某种存储类型的区块数据。`类型` 为 `mca`、`pdc` 或 `linear`，且不能是配置文件中当前启用的存储类型。用于切换存储格式后清理遗留数据（例如在执行 `migrate-world-storage` 之后）。仅支持 Paper，同一时间只能运行一个清理任务。

### feature world-settings

`/ce feature world-settings [世界] [设置项] (值)`

查询或设置世界选项。`值` 为 `true`/`false`/`default`，省略则查询当前值。

## 资源命令

### resource list

`/ce resource list`

列出 `resources` 文件夹下所有包（含启用/禁用状态）。

![](/img/i18n/zh-Hans/commands_17.png)

### resource enable

`/ce resource enable [包名]`

启用指定资源包（写入其 `pack.yml`）。

### resource disable

`/ce resource disable [包名]`

禁用指定资源包。

### resource create

`/ce resource create [包名] (命名空间) (作者) (描述)`

创建新的资源包骨架。未指定命名空间时使用包名作为命名空间。

### resource save-default

`/ce resource save-default [路径]`

重新生成内置默认资源。可用路径：`/default_assets`、`/default_feature_populator`、`/default_templates`、`/internal`、`/legacy_armor`、`/remove_shulker_head`。

### resource search

`/ce resource search [类型] [资源]`

查找某个资源配置定义在哪个文件中。`类型` 为资源的配置类型（如 `craftengine:item`、`craftengine:block`）——Tab 补全会列出所有可搜索的类型，选定类型后会列出其已注册的标识符。输出相对于 `resources` 文件夹的文件路径，点击即可复制绝对路径到剪贴板。

## 调试命令

### debug pack-states

`/ce debug pack-states (玩家)`

查看在线玩家已缓存的资源包偏好。省略玩家时查询自己，控制台必须指定玩家。默认权限：`ce.command.debug.pack_states`。

| 状态 | 颜色 | 含义 |
|:---|:---|:---|
| `enabled` | 绿色 | 玩家已显式启用。 |
| `disabled` | 红色 | 玩家已显式禁用。 |
| `unset` | 黄色 | 尚未保存覆盖值，使用该包配置中的 `default`。 |

展示所有已保存的包 ID，包括本服未配置的包；不存在的包名以删除线标记，例如 ~~old_pack~~，仍显示其保存的状态。本服已配置但没有偏好覆盖的包也会列出。偏好尚未加载时，会显示相应提示。

这里显示的是偏好状态，不代表客户端已经下载或加载成功。

### debug item-data

`/ce debug item-data`

别名：`/ce item debug`

检查主手物品的物品数据（如 NBT 或组件）。可用 `--client-side` 标志查看经过客户端转换（含解密）后的数据。

![](/img/i18n/zh-Hans/commands_8.png)

### debug item-component

`/ce debug item-component [组件] [json/snbt]`

将主手物品的指定数据组件序列化为 JSON 或 SNBT（仅玩家，1.20.5+）。结果包含 CraftEngine 所需的 `(json) ` 或 `(snbt) ` 前缀；点击结果即可将完整字符串复制到剪贴板。

例如，`/ce debug item-component minecraft:custom_name snbt` 返回的值可以直接粘贴到配方的精准匹配谓词或物品的直接组件配置中。

### debug get-block-internal-id

`/ce debug get-block-internal-id [方块状态]`

获取自定义方块状态对应的服务端真实方块命名空间 ID，常用于 WorldEdit 和数据包等工具。

![](/img/commands_9.png)
![](/img/commands_10.png)

:::tip

**问：** 为什么 Minecraft 原生数据包中必须使用真实方块命名空间 ID，例如 `craftengine:custom_666`，而不是像 `default:palm_log` 这样的名称？

**答：** 因为配置文件在服务器启动后才加载，而数据包在服务器初始化阶段就已加载。此时服务器无法识别未注册的方块命名空间 ID。为确保预注册的自定义方块能适配最新用户配置，CraftEngine 采用了容器式动态绑定方案。

:::

![](/img/commands_13.png)

清除玩家的物品冷却。

### debug is-chunk-persistent-loaded

`/ce debug is-chunk-persistent-loaded`

### debug entity-id

`/ce debug entity-id [世界] [实体 ID]`

通过实体 ID 获取实体数据。

### debug custom-model-data

`/ce debug custom-model-data (物品标识符)`

获取物品的自定义模型数据值。省略标识符时使用主手物品。

### debug item-model

`/ce debug item-model (物品标识符)`

获取物品的物品模型值（1.21.2+）。省略标识符时使用主手物品。

### debug image

`/ce debug image [图片标识符] (行) (列)`

获取指定图片在字体中的引用方式（含 MiniMessage、MineDown、RAW 三种格式）。

### debug furniture

`/ce debug furniture`

切换玩家的家具调试模式，用于可视化家具的边界与组成（仅玩家）。

### debug optimize-furniture-structure

`/ce debug optimize-furniture-structure [世界] [文件] (y轴偏移量)`

优化结构存储文件中的家具：移除其中的碰撞实体，并按偏移量调整家具的 Y 坐标。
